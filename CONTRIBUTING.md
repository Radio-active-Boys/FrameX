# 🤝 Contributing to FrameX

Thank you for considering contributing to FrameX!

We welcome pull requests, issue submissions, and suggestions to improve this project. Please follow these guidelines to keep the process smooth.

---

## 🧩 What You Can Contribute

- New features (e.g., new element types, custom analysis modes)
- Bug fixes or performance improvements
- UI/UX enhancements
- Documentation and tutorials

---

## 📋 How to Contribute

1. **Fork the repository**Create your own copy of the repo.
2. **Create a new branch**

   ```bash
   git checkout -b feature/my-feature
   ```
